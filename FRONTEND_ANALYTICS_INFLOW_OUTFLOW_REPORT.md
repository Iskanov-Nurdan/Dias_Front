# Что изменено

## KPI карточки

- Вместо трёх объединённых блоков «Приход / Расход / Прибыль» сделан дашборд из **пяти** карточек с клиентскими названиями.
- **Первый ряд:** Выручка, Себестоимость продаж, Прибыль.
- **Второй ряд:** Затраты производства, Закупки сырья.
- Сетка адаптивная: на узком экране карточки идут столбцом.
- У карточек «Затраты производства» и «Закупки сырья» свои цветовые акценты в полоске сверху.

## Модалки

- Удалена одна общая логика «расхода»; у каждой карточки **свой** тип детализации и свой запрос к API.
- **Выручка** — `revenue-details`, таблица: дата, клиент, продукт, кол-во, цена, выручка.
- **Себестоимость продаж** — `sales-cost-details`, таблица: дата, продажа/заказ, продукт, кол-во, себестоимость за ед., сумма.
- **Прибыль** — `profit-details`, блок итогов (выручка, себестоимость, итог) и таблица: дата, заказ, объект, выручка, себестоимость, прибыль; подписи без «приход/расход».
- **Затраты производства** — `production-cost-details`, таблица из семи колонок: дата, партия (№), профиль, линия, шт, метры, затраты.
- **Закупки сырья** — `purchase-details`, таблица: дата, материал, поставщик, кол-во, цена, сумма.
- Во всех модалках при пустом `items` показывается короткий empty state без пустой таблицы.
- Подпись действия на карточках: «Детали».

## Графики

- Главный график «Динамика» строится по тем же точкам тренда, плюс серия **«Закупки сырья»** (значение берётся из ответа API, если бэкенд отдаёт поле в точке тренда; иначе линия нулевая).
- Легенда и подписи серий только на русском, по смыслу: выручка, себестоимость продаж, прибыль, затраты производства, закупки сырья.
- Высота области графика увеличена для пяти рядов.

## Названия

- Секция сверху: заголовок «Сводка», без «приход/расход».
- Убраны пользовательские подписи «Приход», «Расход» в KPI и на графике.
- В модалке прибыли блоки итогов: «Выручка», «Себестоимость», «Итого».

## Layout

- Новые классы: `analytics-kpi-dashboard`, строки `analytics-kpi-dashboard__row--3` и `--2`.
- Компонент `KpiCard` для единообразия карточек.
- Таблица производственных затрат: классы `detail-table-header--7` / `detail-table-row--7` и сетка колонок в SCSS.

# Что убрано

- Старый визуальный блок «Приход, расход и прибыль» и три сегмента в одной «склейке».
- Подписи KPI «Приход» и «Расход».
- Смешанная детализация одного типа `expense` для карточки себестоимости (заменена на отдельный тип `sales_cost` и отдельные модалки для производства и закупок).

# Что теперь видит клиент

## Блоки на первом экране

1. Сводка из пяти карточек с деньгами по смыслу: продажи, себестоимость продаж, прибыль, производство, закупки сырья.
2. График динамики по периоду с пятью разнесёнными смыслами.
3. Ниже — без изменения смысла: продажи (счётчики), ОТК, склад; объёмы по профилям; клиенты по выручке; производство по линиям.

## Детализации по клику

1. Выручка — только продажи, разбивка по клиенту и продукту.
2. Себестоимость продаж — только строки себестоимости продаж.
3. Прибыль — сводка и построчно по продажам.
4. Затраты производства — только партии производства.
5. Закупки сырья — только приходы сырья.

# Что проверить вручную

- Выручка: карточка, модалка, сумма «Итого» и строки.
- Себестоимость продаж: карточка, модалка, пустой период.
- Прибыль: итоги и таблица, подписи «Выручка» / «Себестоимость».
- Затраты производства: карточка, модалка, колонки шт/м/затраты.
- Закупки сырья: карточка (если в `summary.cards` есть сумма закупок — см. бэкенд), модалка, строки.
- График: все пять легенд, подсказки, периоды при смене года/месяца/диапазона дат.
- Модалки: закрытие по оверлею, скролл таблицы, узкая ширина окна.
- Mobile: два ряда KPI складываются в один столбец; горизонтальный скролл таблиц в модалках при необходимости.
- Desktop: два ряда 3+2 карточек, читаемость легенды графика.
