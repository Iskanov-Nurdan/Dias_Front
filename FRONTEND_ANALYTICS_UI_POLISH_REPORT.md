# Что изменено

## KPI cards
- Период и три главных показателя собраны в одну «герой»-панель с единым фоном и без двойных рамок.
- Карточки KPI переведены на компонентную разметку `analytics-kpi-card`: короткий заголовок, крупная цифра, компактное действие «Детали» / «Разбор».
- Добавлен цветной верхний акцент по типу показателя, ровная сетка из трёх колонок (на мобильных — одна колонка), табличные цифры, hover и focus-visible для доступности.

## main chart
- График вынесен в панель `analytics-panel` с заголовком «Динамика» и коротким поясняющим текстом.
- Сетка осей облегчена: без лишних линий осей, только горизонтальная сетка, мягкие градиенты под выручкой и себестоимостью.
- Легенда заменена на компактный горизонтальный список `analytics-chart-legend` без перегруза.
- Подписи осей и отступы подстроены под читаемость; линии прибыли и затрат на производство визуально разведены по толщине и акценту.

## sales block
- Блок «Продажи» оформлен как карточка второго ряда с единым стилем: только метрики «Сделок» и «Единиц» в формате `dl` / `dt` / `dd`.

## OTK block
- Блок ОТК унифицирован с продажами: три метрики «Годных», «Брак», «Доля брака» без лишних единиц в подписях.

## warehouse block
- Вместо вложенных мини-карточек — три компактные ячейки в одной карточке с лёгким цветовым кодированием (доступно / резерв / отгружено).

## profile chart
- Заголовок заменён на клиентский «Объём по профилям», подзаголовок «Отгружено, шт.».
- Подписи осей укорачиваются при переполнении; в подсказке — «Объём, шт.».
- Имена профилей без технических `#id`: при отсутствии имени показывается «Без названия».

## client chart
- Заголовок «Клиенты», подзаголовок «Выручка»; подсказка в денежном формате.
- Подписи клиентов без `#id`, при отсутствии имени — «Клиент».

## line chart
- Секция «Производство по линиям»: заголовок, короткий подзаголовок, KPI «Партий», «Выпуск, шт», при наличии — «Выпуск, м» в одной шапке с графиком.
- Столбчатый график в той же визуальной системе, что и остальные графики (скругления, сетка, подсказки).

# Что убрано
- Технические названия и `#id` в подписях графиков профилей и клиентов на главном экране.
- Лишние визуальные уровни: отдельная «коробка» тулбара внутри второй «коробки» KPI (тулбар встроен в герой без дублирования тени).
- Тяжёлые вложенные мини-карточки склада внутри большого блока.
- Длинный заголовок графика без структуры; громоздкая стандартная легенда Recharts.
- Лишние подписи метрик («Годных, шт» и т.п.) в пользу коротких клиентских формулировок.

# Что стало лучше
- Иерархия: сначала период и KPI, затем главная динамика, затем сводка бизнес-блоков, затем детальные графики.
- Читаемость: крупные цифры KPI, выровненные секции, единые отступы панелей.
- Компактность: меньше пустого воздуха в карточках, плотнее второй ряд без потери дыхания.
- Client-facing UI: только понятные русские названия показателей и осей в пользовательской части экрана.

# Что проверить вручную
- desktop: сетка KPI, график, второй ряд из трёх карточек, два графика в ряд, блок производства.
- tablet: переносы гридов, читаемость легенды и осей.
- mobile: KPI в одну колонку, второй ряд — колонкой, графики без обрезания, высота главного графика.
- empty states: отсутствие данных по трендам / профилям / клиентам / линиям.
- cards: клики по KPI открывают те же модалки, что и раньше.
- charts: подсказки и подписи периода при разных `trend_group`.
