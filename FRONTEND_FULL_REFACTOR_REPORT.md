# Что было плохо

- Контент без жёсткой ширины воспринимался «растянутым» на широких мониторах (`--content-max-width` 1280px).
- Модальные окна: оверлей без отступов от краёв, на узкой высоте контент мог упираться в край; на мобилке вертикальное выравнивание по центру мешало прокрутке длинных форм.
- Выпадающий список `Select`: длинные подписи пунктов без ellipsis и без `title` для подсказки.
- Фильтры (`FiltersModal`): на мобилке центрированное окно, не нижний sheet.
- Таблицы на кастомных grid с `min-width` 680–1100px: на мобилке горизонтальный скролл и «каша» вместо читаемых карточек (Сырьё, Химия, Рецепты, Профили, Производство, ОТК, Линии — открытие/история).
- Линии, вкладка «Открытие»: сетка была на 6 колонок при 8 полях в строке — ломало выравнивание на десктопе.

# Что исправлено

## По страницам

- **Глобально / layout:** `--content-max-width` 1184px; оверлей модалок с padding и прокруткой; на мобилке оверлей `align-items: flex-start` для длинных модалок.
- **Сырьё (`MaterialsPage`):** на `max-width: 768px` таблицы каталог / остатки / партии / движения → карточки с подписями полей, `min-width` снят, горизонтальный скролл у обёртки отключён.
- **Химия (`ChemistryPage`):** то же для каталога, остатков, партий.
- **Рецепты (`RecipesPage`):** основная таблица рецептов → карточки на мобилке.
- **Профили (`PlasticProfilesPage`):** таблица → карточки на мобилке.
- **Производство (`ProductionPage`):** таблица партий → карточки на мобилке.
- **ОТК (`OTKPage`):** очередь и история → карточки на мобилке.
- **Линии (`LinesPage`):** исправлена сетка «Открытие» на 8 колонок; `min-width` открытия только на десктопе; на мобилке открытие и богатая история → карточки; горизонтальный скролл у `lines-table-scroll` отключён на мобилке.
- **Склад / Продажи:** широких grid-таблиц с принудительным `min-width` не найдено; правки не потребовались.

## Компоненты

- **`Select`:** `title` на пункте, внутренний span с ellipsis для длинного текста (desktop + mobile sheet).
- **`FiltersModal`:** на мобилке прижатие снизу, полная ширина, скругление верхнее, анимация `filtersSheetIn`, sticky footer сохранён.

- Единая сетка 8px через существующие `--space-*` и новые layout-классы.
