# Спецификация: GET /api/clients/ — Разовые клиенты и поиск

## Колонки таблицы «Разовый»

| Колонка | Описание | Источник данных |
|---------|----------|-----------------|
| Имя | ФИО клиента | `fio` |
| Месяц | Месяц из date_start | `date_start` → месяц |
| Год | Год из date_start | `date_start` → год |
| Оплата | **Цена клиента** (с учётом скидки) | `price`, `discount` → priceFinal = price × (1 − discount/100) |
| Действие | Кнопка «Добавить» | — |

**Важно:** колонка «Оплата» показывает **цену клиента** (price с учётом discount), а не сумму разовых оплат (oneTimeTotal). Изначально может быть 0 или 180 и т.д. Дальше пользователь увеличивает сумму через «Добавить».

## Фильтр по типу

**Обязательно:** в списке должны быть только клиенты с `clientType = 'one-time'` (Разовый). Бэкенд должен фильтровать по параметру `clientType=one-time` в запросе.

## Требования к полям в ответе

Для каждого клиента в `GET /api/clients/?clientType=one-time&...` должны быть поля:
- `price` — базовая цена (число)
- `discount` или `discount_percent` — скидка в % (число, 0 если нет)
- `date_start` или `dateStart` — дата начала (для Месяц/Год)

---

## Параметры запроса (фронт передаёт)

| Параметр    | Тип    | Описание                                      |
|-------------|--------|-----------------------------------------------|
| `clientType`| string | `one-time` — только разовые клиенты           |
| `search`    | string | Поиск по ФИО и телефону (подстрока, icontains)|
| `year`      | string | Год фильтра по date_start (опционально)       |
| `month`     | string | Месяц 1–12 (опционально, только при year)   |
| `dateFrom`  | string | Альтернатива: `YYYY-MM-DD`                    |
| `dateTo`    | string | Альтернатива: `YYYY-MM-DD`                    |
| `page`      | number | Страница                                      |
| `perPage`   | number | Записей на странице (20)                      |

## Требования к бэкенду

### 1. Поиск (`search`)
- Фильтр по полям: `fio` (ФИО) и `phone` (телефон)
- Регистронезависимый: `icontains` или `iregex`
- Работает совместно с `clientType`, `year`, `month`

### 2. Фильтр по дате (`year`, `month` или `dateFrom`, `dateTo`)
- Фильтрация по полю `date_start` клиента
- `year` — год date_start
- `month` — месяц date_start (1–12)
- Если `year` пустой — не фильтровать по дате (все годы)
- Если `month` пустой при указанном `year` — весь год

### 3. clientType=one-time
- Фильтр: `client_type = 'one-time'` (или `clientType` в зависимости от сериализатора)
- Аннотация `one_time_total` через Subquery (без дублирования строк)

### 4. Порядок применения фильтров
1. Базовый queryset: Client
2. Фильтр по clientType
3. Фильтр по search (Q(fio__icontains=search) | Q(phone__icontains=search))
4. Фильтр по year/month (date_start)
5. annotate(one_time_total=...)
6. distinct() при необходимости
7. Пагинация

## Пример корректного запроса
```
GET /api/clients/?clientType=one-time&search=аб&page=1&perPage=20
```
Должен вернуть всех разовых клиентов, у которых ФИО или телефон содержит «аб».

## Пример без фильтра по дате
```
GET /api/clients/?clientType=one-time&search=аб
```
Без year/month — все разовые клиенты, подходящие по поиску.

## Пример с фильтром по дате
```
GET /api/clients/?clientType=one-time&search=аб&year=2026&month=1
```
Только разовые клиенты с date_start в январе 2026, ФИО/телефон содержит «аб».
