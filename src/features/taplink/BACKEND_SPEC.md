# Taplink — Спецификация для бэкенда

> Фронтенд полностью готов. Когда бэкенд реализует эти эндпоинты,
> достаточно поменять одну строку в `api.js`:
> `export const BACKEND_ENABLED = true;`

---

## Авторизация

Все `PUT` / `POST` / `DELETE` запросы требуют заголовок:
```
Authorization: Bearer <access_token>
```
Токен тот же, что используется во всём приложении (`localStorage.getItem('token')`).

`GET /api/taplink/` — **публичный**, без авторизации (страница открыта для всех).

---

### 2. Сохранить конфиг страницы
```
PUT /api/taplink/
Content-Type: application/json
Authorization: Bearer <token>
```
- Тело: **тот же формат**, что и ответ `GET /api/taplink/`
- Поля `photo`, `bg`, `videos[*]` содержат **URL** файлов (строки вида `"/media/taplink/abc.jpg"` или пустую строку `""` / `null`)
- Ответ `200 OK`: сохранённый объект (тот же формат)
- Ответ `400 Bad Request`:
```json
{ "error": { "message": "Описание ошибки" } }
```

---

### 3. Загрузить файл (фото или видео)
```
POST /api/taplink/upload/
Content-Type: multipart/form-data
Authorization: Bearer <token>
```
Поля формы:
| Поле      | Тип    | Описание                                                                                      |
|-----------|--------|-----------------------------------------------------------------------------------------------|
| `file`    | File   | Загружаемый файл                                                                              |
| `context` | string | Подсказка для организации файлов: `hero-bg`, `sport-photo`, `trainer-photo`, `sport-video`, `trainer-video` |

Ответ `201 Created`:
```json
{
  "url": "https://rahmanata.kg/media/taplink/uploads/abc123.jpg"
}
```
Ошибки:
```json
{ "error": { "message": "Файл слишком большой. Максимум 20 МБ." } }
```

Ограничения:
- **Изображения**: JPEG, PNG, WEBP — до **5 МБ**
- **Видео**: MP4, WEBM — до **200 МБ**
- Хранить в папке `media/taplink/` (или CDN)
- URL должен быть абсолютным (начинаться с `https://`) или корневым (`/media/...`)

---

### 4. Удалить файл
```
DELETE /api/taplink/upload/
Content-Type: application/json
Authorization: Bearer <token>
```
Тело:
```json
{ "url": "https://rahmanata.kg/media/taplink/uploads/abc123.jpg" }
```
Ответ `204 No Content` или `200 OK`.

## Модель данных (типы полей)

### hero
| Поле       | Тип    | Обязательно | Описание                        |
|------------|--------|-------------|---------------------------------|
| `title`    | string | да          | Заголовок (крупный текст)       |
| `subtitle` | string | да          | Подзаголовок (красный акцент)   |
| `desc`     | string | да          | Строка описания                 |
| `bg`       | string\|null | нет  | URL фонового фото или `null`    |

### stats[]
| Поле | Тип    | Описание             |
|------|--------|----------------------|
| `n`  | string | Число/значение       |
| `l`  | string | Подпись под числом   |

### sports[]
| Поле       | Тип          | Описание                                    |
|------------|--------------|---------------------------------------------|
| `id`       | int          | Уникальный идентификатор                    |
| `name`     | string       | Название секции                             |
| `emoji`    | string       | Эмодзи (резервный дисплей без фото)         |
| `photo`    | string\|null | URL фото или `null`                         |
| `gradient` | string       | CSS-градиент (резервный фон без фото)       |
| `desc`     | string       | Описание секции                             |
| `schedule` | Schedule[]   | Расписание (см. ниже)                       |
| `videos`   | string[3]    | Массив из 3 URL видео (пустая строка = нет) |

### sports[].schedule[]
| Поле      | Тип    | Описание               |
|-----------|--------|------------------------|
| `id`      | int    | Идентификатор строки   |
| `group`   | string | Группа (Взрослые/Дети) |
| `days`    | string | Дни (Пн, Ср, Пт)       |
| `time`    | string | Время (18:00–20:00)    |
| `trainer` | string | ФИО тренера            |

### trainers[]
| Поле           | Тип       | Описание                           |
|----------------|-----------|------------------------------------|
| `id`           | int       |                                    |
| `name`         | string    | ФИО тренера                        |
| `sportName`    | string    | Название вида спорта               |
| `emoji`        | string    | Эмодзи (резерв без фото)           |
| `photo`        | string\|null | URL фото или `null`             |
| `experience`   | string    | Стаж (напр. "12 лет")              |
| `achievements` | string[]  | Массив достижений                  |
| `shortBio`     | string    | Короткое описание для карточки     |
| `bio`          | string    | Полное описание для детального окна |
| `videos`       | string[3] | Массив из 3 URL видео              |

### prices[]
| Поле    | Тип     | Описание                        |
|---------|---------|---------------------------------|
| `id`    | int     |                                 |
| `name`  | string  | Название тарифа                 |
| `price` | string  | Цена (напр. "4 200 сом")        |
| `desc`  | string  | Пояснение (напр. "350 сом/зан") |
| `hot`   | boolean | Выделенный тариф ("Популярное") |

### offer
| Поле      | Тип     | Описание                              |
|-----------|---------|---------------------------------------|
| `enabled` | boolean | Показывать баннер или нет             |
| `label`   | string  | Метка (напр. "Акция")                 |
| `title`   | string  | Заголовок баннера                     |
| `desc`    | string  | Описание                              |
| `btn`     | string  | Текст кнопки                          |

### footer
| Поле        | Тип    | Описание                              |
|-------------|--------|---------------------------------------|
| `phone`     | string | Телефон для отображения               |
| `whatsapp`  | string | Номер WhatsApp (цифры, напр. 77001234567) |
| `telegram`  | string | Username Telegram (без @)             |
| `instagram` | string | Username Instagram (без @)            |
| `tiktok`    | string | Username TikTok (без @)               |
| `email`     | string | Email                                 |
| `address`   | string | Адрес                                 |
| `mapUrl`    | string | Ссылка на 2GIS или Google Maps        |
| `copy`      | string | Строка авторских прав                 |

## Хранение в БД

Рекомендуется хранить весь конфиг как **один JSON-документ** в одной строке таблицы `taplink_config`:

```sql
CREATE TABLE taplink_config (
  id         SERIAL PRIMARY KEY,
  data       JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  updated_by INTEGER REFERENCES users(id)
);
```

При `GET` — возвращать `data` последней строки.  
При `PUT` — вставлять новую строку (история изменений) или обновлять существующую.

---

## Формат ошибок (единый для всех эндпоинтов)

```json
{
  "error": {
    "message": "Человекочитаемый текст ошибки"
  }
}
```
HTTP коды: `400`, `401`, `403`, `413` (файл слишком большой), `500`.

---

## Примечания по видео

Видео-файлы загружаются через тот же `POST /api/taplink/upload/` (поле `context`: `"sport-video"` / `"trainer-video"`).  
В поле `videos[i]` хранится URL видео на сервере.

> В текущей версии фронтенда видео из editor сохраняются как `blob:` URL только на время сессии.  
> После подключения бэкенда — видео сразу загружаются на сервер через этот же эндпоинт.
